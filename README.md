# ml-e2e-project
## Course Lead Conversion Prediction

A course provider receives enquiries from potential customers but has limited capacity to follow up with every lead. This project estimates each lead’s probability of conversion using information available before the conversion decision.

The predictions could help the team prioritise follow-up. We will start with Logistic Regression, compare it with a tree-based model, and evaluate performance on unseen leads. We will assess both missed converters and unnecessary contacts.
